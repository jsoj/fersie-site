# Fersie Institutional Marketing Site (`fersie-site`)

Lightweight, high-performance static marketing website for the Fersie brand, showcasing fashion collections (roupas de alfaiataria e bijuterias), brand story, and direct WhatsApp customer support integration.

## Features
- **HTML5 & Vanilla CSS**: Fast, modern, responsive frontend styled with `fersie-design-system`.
- **Collections Showcase**: Dedicated pages for Roupas (Tailoring) and Bijuterias (Jewelry & Accessories).
- **WhatsApp Support Integration**: Direct CTAs for personalized customer inquiry.
